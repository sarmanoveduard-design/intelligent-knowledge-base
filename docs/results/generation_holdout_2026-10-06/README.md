# Generation benchmark — MAIN 119

Дата: 2026-10-06

## Что сравнивалось

Три модели генерации отвечали на один и тот же набор из 119 approved-вопросов:

- Qwen3:8B
- GPT-5.6 Luna
- GPT-5.6 Terra

Для всех моделей использовались:

- один и тот же frozen Top-10 контекст;
- один и тот же prompt;
- один и тот же набор из 119 вопросов.

Модели не прогонялись повторно для этапа judge.
Для проверки использовались уже полученные ранее ответы.

## Дополнительная проверка GPT-5.6 Sol

После получения ответов трёх моделей GPT-5.6 Sol использовался отдельно только как проверяющая модель.

Для каждого вопроса Sol получал:

- исходный вопрос;
- frozen Top-10 контекст;
- reference answer_hint;
- три обезличенных ответа A / B / C.

Sol не видел названия моделей.

Порядок A / B / C менялся между вопросами.

Всего Sol проверил 119 комплектов ответов.

## Важное замечание по critical-флагам

После Sol все случаи, помеченные как critical, были дополнительно просмотрены по исходному frozen Top-10.

Выявлено, что вопросы 57 и 116 содержат проблему контекста/retrieval:
часть информации, необходимой для полного эталонного ответа, отсутствовала в переданном моделям Top-10.

Поэтому raw critical-флаги Sol для Luna и Terra на этих вопросах нельзя интерпретировать как чистую ошибку генерации.

Для Qwen большинство отмеченных Sol проблем подтверждаются исходными материалами.
В некоторых случаях степень серьёзности ошибки может быть дискуссионной, поэтому raw judge output сохранён отдельно и не заменяется ручной интерпретацией.
