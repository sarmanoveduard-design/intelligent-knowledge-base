# Интеллектуальная база знаний

Универсальная система на основе RAG для работы с документами.

## Цель

Система должна принимать разные документы, извлекать из них информацию и отвечать на вопросы пользователя только на основании найденных источников.

Основной конвейер:

документ
→ регистрация
→ версия
→ извлечение текста
→ нормализация
→ chunking
→ embeddings
→ векторный поиск
→ RAG-ответ
→ ссылка на источник
→ проверка качества

Архитектура не должна зависеть от конкретного набора документов или одной предметной области.

## Поддерживаемые документы

На текущем этапе:

- DOCX
- PDF с текстовым слоем

Поддержка сканированных PDF через OCR будет добавлена отдельно.

## Что уже реализовано

### Приём документов

- регистрация файлов;
- SHA-256;
- поиск точных дубликатов;
- реестр документов.

### Версионирование

Поддерживаются состояния:

- draft
- active
- superseded
- archived

При появлении новой активной версии предыдущая активная версия переводится в superseded.

### DOCX

Реализовано:

- извлечение текста;
- нормализация;
- обработка текста внутри гиперссылок Word;
- проверка отсутствия потери текста.

### PDF

Реализовано извлечение текста с сохранением номера страницы.

### Структурный анализ

Есть дополнительная возможность определять:

- metadata;
- title;
- table of contents;
- section;
- content.

Этот модуль является дополнительным улучшением и не является обязательным для работы RAG.

### Тесты

Сейчас проходит 51 автоматический тест.

## Текущий конвейер

Реализовано универсальное внутреннее представление:

PDF / DOCX
→ SourceBlock
→ Chunk

Chunking не зависит от конкретного документа или предметной области и сохраняет связь с исходным файлом, страницами и абзацами.

## Безопасность данных

Рабочие документы и закрытые материалы не публикуются в Git.

Каталоги:

data/incoming/
data/processed/

исключены из репозитория.

## Запуск

Сборка Docker:

docker compose build

Запуск тестов:

docker compose run --rm app python -m unittest discover -s tests -v

Сканирование входящих документов:

docker compose run --rm app python -m knowledge_base.cli scan

## Статус

Проект находится в активной разработке.

Текущий фокус — универсальное и надёжное RAG-ядро, которое сможет работать с новыми документами независимо от их содержания.
